# Use selective handwritten typography for scorebook expression

The approved scorebook direction depends on handwriting to distinguish expressive page titles, player names, play notation, annotations, and short controls from generic iOS chrome. Bundle Patrick Hand for those roles, while retaining semantic SF Pro text styles and monospaced system digits for dense statistics, forms, alerts, timers, counts, and accessibility-critical content; this trades a small font-bundling and testing cost for the intended scorebook identity without sacrificing rapid reading.
